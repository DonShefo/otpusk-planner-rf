# 3.0.0: переносимая база графиков отпусков

Статус: кандидат выпуска в PR. Публикация, тег и замена текущей версии не выполнены.

## Главное

Данные всех лет сохраняются в один пользовательский JSON. В поддерживаемом браузере доступ к файлу запоминается, изменения записываются автоматически и проверяются повторным чтением. При переезде между терминальными серверами выбирается тот же файл из переносимых «Документов». Программы устанавливать не нужно.

## Изменения

- Прямая запись, ручное скачивание и браузерная запасная копия имеют разные статусы.
- Импорт v1/v2/v3 валидирует данные до применения, поддерживает BOM и добавление новых лет без удаления существующих.
- Состав, должности и настройки каждого года независимы. Удаление сотрудника ограничено текущим годом.
- Одна предыдущая запись хранится в JSON, копия перед открытием/импортом сохраняется в браузере. Есть явный откат.
- Внешняя правка файла, отказ доступа и сбой записи останавливают автосохранение с объяснением.
- Обновление праздников через интернет сохранено: xmlcalendar.ru и зеркало, проверка по федеральному перечню, отсутствие замены при ошибке, источник и время успешного обновления.
- Исправлен расчёт отпуска через Новый год; переходящие периоды видны на графике следующего года.
- Исправлены ложные предупреждения о совпадении должностей внутри длинного объединённого окна перегрузки.
- Закреплены сотрудник и заголовки таблицы, исправлен фокус после добавления, доступны подписи полей, пустой график не выдаётся за завершённый.
- Приложение распаковано из непрозрачного бандла в читаемые исходники; конечный HTML по-прежнему один и не требует зависимостей.

## Проверено

- 28 проверок модели, календаря, миграции и файловой записи на Node.js.
- Браузерные сценарии: перенос базы в чистый профиль, история годов, прямая запись в FileSystemFileHandle, автосохранение, восстановление дескриптора из IndexedDB, остановка при внешнем изменении, откат, некорректный импорт, обновление/ошибки календаря, Excel, темы, узкий экран, печать, заблокированное/повреждённое localStorage.
- Снимки реального онлайн-XML 2026/2027, полученные 04.11.2026. Федеральный перечень сверен по Минтруду и Банку России.

## Ограничения

Файловый диалог Windows, сетевые «Документы» и доменные политики требуют проверки на рабочем сервере. Одновременное редактирование файла с нескольких серверов не поддерживается. Скачанный файл браузер не даёт повторно прочитать без выбора пользователем, поэтому такой способ не помечается как подтверждённая прямая запись.
